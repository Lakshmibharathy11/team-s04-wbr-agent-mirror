# V1 Integration Contract

## Tool output envelope
Every tool returns:
- `tool_name`
- `request_id`
- `status`: `ok | partial | error`
- `generated_at`
- `parameters`
- `data`
- `evidence_refs`
- `warnings`
- `error`

Rules:
- numbers stay numeric;
- no arbitrary SQL generated by the model;
- every result carries evidence/query references;
- partial/error states are explicit;
- missing evidence is never silently filled in.

## Analyst report claim
Each claim carries:
- `claim_id`
- `question_id`
- `statement`
- `claim_type`: `fact | observed_pattern | unexplained`
- `confidence`
- `supporting_evidence`
- `causal_language_allowed`
- `requires_human_review`

Verifier outcome per claim:
- `keep`
- `downgrade`
- `flag`
- `remove`

## Failure contract
Athena/external tool failure:
1. retry once;
2. mark partial;
3. preserve the failure;
4. never invent values;
5. verifier cannot pass claims with unavailable evidence.
